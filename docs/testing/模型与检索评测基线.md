# 模型与检索评测基线

更新时间：2026-06-03

本文说明当前项目用于验证 RAG 查询链路、模型 provider、检索质量、citation 和降级行为的评测基线。本文面向开发和验收，不替代线上监控。

## 评测目标

Little Bear 的评测不只看回答是否“像是对的”，而是同时验证：

- 当前账号只能检索有权限访问的知识库和文档。
- 多知识库自动搜索能覆盖用户可访问范围。
- Query Rewrite 能把联合问题拆成多个可检索 query。
- 向量召回、关键词召回、融合、rerank 和质量 gate 能产出相关候选。
- Context Builder 能保留足够上下文，并控制 token 预算。
- LLM 回答必须可由 citation 支撑。
- citation 失败、模型失败、检索失败时必须结构化降级。
- 查询日志、模型调用日志和诊断记录不泄露完整 prompt、文档原文或 secret。

## 查询回归数据集

当前 RAG 增强回归样例位于：

```text
docs/examples/query-regression.rag-enhancement.jsonl
```

每一行是一个 JSON 对象。评测脚本会读取用例、登录测试账号、加载可访问知识库、执行查询并写入记录文件。

常用字段含义：

- `case_id`：用例唯一标识。
- `query`：用户问题。
- `kb_ids`：显式指定知识库 ID；为空时由服务端按权限自动搜索。
- `mode`：查询模式。
- `top_k`：候选数量。
- `include_sources`：是否要求返回引用来源。
- `expect_answer`：是否期望生成答案。
- `min_citations` / `max_citations`：引用数量约束。
- `allow_degraded`：是否允许降级通过。
- `expected_degrade_reasons`：允许或期望的降级原因。
- `expected_answer_terms`：答案中应出现的关键术语。
- `forbidden_answer_terms`：答案中不应出现的术语。
- `expected_citation_title_terms`：引用标题应包含的术语。
- `expected_doc_ids` / `expected_source_ids`：期望命中的文档或来源。
- `run_stream`：是否同时验证 SSE 流式查询。

测试账号和 API 地址通过环境变量注入，不应写入数据集文件。

## 推荐评测维度

### 检索覆盖

关注指标：

- 是否命中正确文档。
- 联合问题是否覆盖每个子问题。
- 自动知识库搜索是否覆盖当前用户可访问知识库。
- 权限过滤后是否还保留足够候选。
- 关键词召回和向量召回是否互补。

失败信号：

- 分开问能命中，合并问无法命中第二个问题。
- 引用只来自一个文档，但问题明显跨文档。
- 无关 chunk 进入上下文并诱导 LLM 胡答。

### 候选质量

关注指标：

- rerank 后候选是否与问题相关。
- 候选质量 gate 是否过滤明显无关片段。
- MMR 去冗余是否避免相同文档重复占满上下文。
- 相邻 chunk 扩展是否补齐上下文。

失败信号：

- 候选数量足够但答案仍缺少关键事实。
- 所有候选来自同一小段内容。
- rerank provider 降级后相关性明显变差。

### 回答和引用

关注指标：

- 回答事实是否由引用支撑。
- citation 格式是否通过校验。
- citation 来源是否当前用户有权限读取。
- citation 自动修复是否只附加已有候选，不伪造来源。

失败信号：

- LLM 输出不存在的引用占位符。
- citation unauthorized。
- citation_missing。
- citation_invalid_format。
- 答案包含引用中没有的关键结论。

### 降级行为

允许降级但不允许无解释失败。

降级必须满足：

- 响应中标记 degraded。
- 返回简短中文降级原因。
- 查询日志记录降级阶段。
- 模型调用日志记录 provider 错误码或超时信息。
- 无法生成可靠答案时仍返回“为什么没有答案”的说明。

### 安全边界

必须覆盖：

- 跨部门文档不可见。
- deleted / blocked / archived / draft 内容不可命中。
- 权限收紧后的旧索引不可继续暴露。
- source 读取重新鉴权。
- 管理后台列表和详情接口都做后端权限过滤。

## 评测记录

查询回归默认写入：

```text
artifacts/query-regression-rag-latest.json
```

该目录可能包含测试过程细节，不应提交包含敏感数据的 artifacts。

记录中重点查看：

- 每个 case 的 `status`。
- 引用数量和引用标题。
- 是否 degraded。
- 降级原因。
- 非流式和流式结果是否一致。
- 请求耗时。

## 基线维护规则

新增业务能力时，应同步新增或调整回归用例：

- 新增 Query Rewrite 策略：补联合问题、歧义问题和短问句用例。
- 新增检索策略：补向量、关键词、融合、rerank 对照用例。
- 新增权限策略：补跨部门、跨知识库、blocked、deleted、权限收紧用例。
- 修改 citation 策略：补引用格式、source 读取、自动修复和 unauthorized 用例。
- 修改 provider 接入：补 provider unavailable、HTTP 401、超时、响应结构异常用例。

不应为了让测试通过而放宽：

- 权限过滤。
- citation 校验。
- candidate gate。
- draft / deleted / blocked / archived 状态过滤。
- ServiceBootstrap。

## 交付边界

- 仓库提供脚本化回归和冒烟测试，不包含独立的离线 IR 指标仪表盘。
- 评测基线以 JSONL 用例和运行记录为主，不包含 nDCG、MRR、Recall@K 等完整检索指标的自动计算。
- 最终答案缓存不属于交付版运行链路，因此评测不覆盖答案缓存命中后的权限二次校验。
