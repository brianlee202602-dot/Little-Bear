# 测试与验收策略

更新时间：2026-06-03

本文说明 Little Bear 交付版测试命令、适用场景和变更验收策略。本文基于仓库内的 `Makefile`、`pyproject.toml` 和前端 package scripts。

## 1. 测试目标

测试策略围绕以下风险展开：

- 权限越权。
- draft / deleted / blocked 文档被查询命中。
- 导入、索引、发布和重建索引状态不一致。
- 模型 provider 波动导致无解释失败。
- 配置和 Secret 变更导致 ServiceBootstrap 不可用。
- 前后端 DTO 不一致。
- 管理后台列表绕过后端分页、筛选或权限过滤。

## 2. 后端快速门禁

日常后端改动优先运行：

```bash
make PYTHON=.venv/bin/python test
```

当前该命令执行：

```text
ruff check apps/api tests tools
pytest -q tests/unit
```

适用场景：

- 纯 Python 逻辑调整。
- service / policy / repository 小范围改动。
- 错误码、降级策略、权限判断改动。
- 文档导入和查询链路的单元行为修复。

## 3. Qdrant / embedding 集成测试

涉及 Qdrant、embedding、索引写入和索引发布时运行：

```bash
make PYTHON=.venv/bin/python test-integration-qdrant
```

适用场景：

- chunk index ref。
- draft / active index。
- Qdrant collection。
- embedding 维度。
- 索引 payload。
- 文档重建索引。
- 权限 payload 刷新。

该测试依赖外部服务可用，应在基础设施启动并配置正确后执行。

## 4. 交付版冒烟测试

主链路冒烟测试用于验证初始化后的基础业务链路：

```bash
make PYTHON=.venv/bin/python smoke-p0
```

适用场景：

- 发布前检查。
- 登录、知识库、导入、查询主链路变更。
- ServiceBootstrap、active config、Secret Store 相关变更。

运行前需要在环境中配置 smoke 所需账号、密码、API 地址和测试知识库信息。

## 5. 查询回归

交付版查询回归：

```bash
make PYTHON=.venv/bin/python query-regression-p0
```

RAG 增强查询回归：

```bash
make PYTHON=.venv/bin/python query-regression-rag
```

适用场景：

- Query Rewrite。
- 多 query 召回。
- 服务端全权限知识库自动搜索。
- 关键词召回、向量召回、融合、rerank。
- candidate quality gate。
- Context Builder。
- citation 校验和自动修复。
- 降级策略调整。

如果修改了测试问题或预期结果，应同步更新对应回归样例，并保留失败原因说明。

## 6. 发布前验收

发布前组合门禁：

```bash
make PYTHON=.venv/bin/python release-smoke-p0
```

该命令组合执行交付版冒烟测试和交付版查询回归，适用于准备交付、演示或合入高风险 RAG / 权限 / 导入改动前的最后检查。

## 7. 前端类型检查与构建

普通查询前端：

```bash
npm run typecheck:web
npm run build:web
```

管理后台前端：

```bash
npm run typecheck:admin
npm run build:admin
```

适用场景：

- Vue 组件改动。
- API client / DTO 改动。
- 交互状态、列表分页、筛选条件和弹窗改动。
- 查询前端流式响应展示改动。
- 管理后台诊断、知识库、用户、配置等页面改动。

涉及两个前端应用共享契约时，应同时运行 web 和 admin 的 typecheck / build。

## 8. 数据库迁移验收

涉及 migration 或 schema 改动时运行：

```bash
make PYTHON=.venv/bin/python db-upgrade
make PYTHON=.venv/bin/python db-current
make PYTHON=.venv/bin/python test
```

验收重点：

- 空库可以从当前 migration head 执行成功。
- 约束、索引、外键和状态枚举由 migration 表达，而不是只靠 service 代码。
- ServiceBootstrap 能识别当前 schema revision。
- 业务代码和测试使用的新字段已存在。

## 9. 权限安全回归

涉及权限、知识库、文档、查询、索引、缓存或 source 读取时，必须覆盖以下安全场景：

- 普通用户调用管理员接口被拒绝。
- 无 scope、错 scope、过期 token 被拒绝。
- 跨部门文档不可查询。
- 用户可见知识库不代表可见其中所有文档。
- 文档权限收紧后旧索引不可继续命中。
- deleted document 不可查询。
- blocked document 不可查询。
- draft index 不可查询。
- archived index 不可查询。
- source 详情读取必须重新鉴权。
- citation unauthorized 必须抑制原答案。
- access block 命中的内容不得进入上下文。

这些场景不能只靠前端菜单隐藏验证，应由后端单元、API 或集成测试覆盖。

## 10. 不同变更类型的建议门禁

| 变更类型 | 最低门禁 | 建议追加 |
| --- | --- | --- |
| 文档-only | 链接和引用扫描 | 无 |
| 后端纯规则 | `make PYTHON=.venv/bin/python test` | 相关单测定向运行 |
| 权限改动 | `make PYTHON=.venv/bin/python test` | 权限安全回归、交付版查询回归 |
| 查询 RAG 改动 | `make PYTHON=.venv/bin/python test` | `query-regression-p0`、`query-regression-rag` |
| 导入 / 索引改动 | `make PYTHON=.venv/bin/python test` | `test-integration-qdrant`、smoke |
| 配置 / Secret / Bootstrap | `make PYTHON=.venv/bin/python test` | smoke、手工发布配置验证 |
| migration 改动 | `db-upgrade`、`db-current`、`test` | 空库重建验证 |
| 普通前端改动 | `typecheck:web` | `build:web` |
| 管理后台改动 | `typecheck:admin` | `build:admin` |
| 前后端契约改动 | 对应前端 typecheck + 后端 test | OpenAPI、SDK、DTO 同步检查 |
| 发布候选 | `release-smoke-p0` | 前端双 build、Qdrant 集成 |

## 11. 交付边界

- 测试策略包含单元、集成、冒烟测试和查询回归，但不是所有权限边界都具备独立端到端用例。
- 外部 provider 依赖的测试需要真实服务可用，失败时应区分“代码失败”和“环境不可用”。
- 前端构建通过不代表真实权限安全通过，权限边界必须以后端测试为准。
